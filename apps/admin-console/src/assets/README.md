# Scene background

`cherry-grove.jpg` is a temporary local preview asset for the live-scene area.

- Source image: https://wallpaperaccess.com/full/25940216.jpg
- Gallery page: https://wallpaperaccess.com/minecraft-sakura

It is bundled only so the launcher can be designed and reviewed without a running
Fabric Bridge. The production scene is the live game frame; replace this file
when the bridge is connected.

`dafeiyu.png` is the character reference supplied by the project owner. It is
transparent-cut from the original JPEG and used for the in-app character card
and the desktop icon. Character artwork rights still need to be cleared before
public distribution; see the persona note in `README.md`.
