# 核心功能计划

目标：让 Agent 在《我的世界》中实际游玩，并与直播观众互动。当前功能状态见 [实现状态](status.md)，任务跟踪见 [核心目标 #32](https://github.com/XiaoFeiASK/CraftMate/issues/32)。

优先打通一条真实的互动流程：

1. 真实直播间的评论进入 Agent 决策。
2. 真实模型结合评论和人格生成回应及受控动作。
3. 真实 Minecraft 身体执行至少一个可观察的动作，操作员可以接管和停止。
4. 真实语音播放回应；管理端显示连接、评论、决策、动作结果和错误。
5. 承诺与经确认的观众记忆可以记录和查询。

以真实环境中的评论、动作和声音验证完整流程。已有模拟和自动化测试用于开发回归，不能代替真实环境验证；具体功能按需要单独拆分。

原有的长时运行、镜头与节目化设想保留在 [历史版本](https://github.com/XiaoFeiASK/CraftMate/blob/c0c056274512aa737c5da2af1771dcc40ef2c33f/docs/delivery-plan.md)，后续按实际需要评估。
