# 场景回归

> 单元测试证明协议和纯函数正确；本文验证“观察 → 规划 → 动作 → 世界证据”的
> 真实 1.20.1 链路。每个场景必须有 `changes` 或服务器侧查询作为证据。

## 运行顺序

```bash
npm run typecheck
npm test
npm run db:check
npm run check:bridge
npm run check:control
```

场景在专用存档 `craftmate-autonomy` 中执行。开始前记录位置、背包、血量和时间；
结束后用 `changes`、方块查询或背包差量断言结果。失败时保留 `problem`、
`remaining` 和 `attempts`，不要只截“看起来在动”的图。

## 矩阵

| # | 场景 | 前置 | 期望动作 | 世界证据 | 失败时应看到 |
| --- | --- | --- | --- | --- | --- |
| 1 | 空手开局 | 空背包、附近有树 | `chop_tree` → `craft` 木板/工作台 | 原木减少、工作台出现 | 可见树但不可达或 `E_WORLD_CHANGED` |
| 2 | 木镐链路 | 有原木、无工作台 | 木板 → 工作台 → 木棍 → 木镐 | 背包出现木镐 | 缺料时报告缺什么 |
| 3 | 石具与矿道 | 有木镐、附近有石头 | `mine_block` / 复用矿道 | 方块变空气、掉落入包 | 服务端复原方块必须判失败 |
| 4 | 夜晚无床 | 夜间、露天、无床 | 继续就地制作/熔炼/矿道工作 | 时间推进，背包或方块变化 | 生成临时小屋、竖井或无界等待 |
| 5 | 岩浆边 | 距岩浆 2 格内 | 反射先退开，再由 Agent 规划 | 距离增加、血量不继续下降 | 只有 `lava` 事件，没有移动 |
| 6 | 苦力怕贴脸 | 4 格内生成苦力怕 | 反射后退，随后战斗或撤离 | 存活且距离拉开 | 下一轮回到原动作 |
| 7 | 高处坠落 | 从 3 格以上落下 | 反射报告 `falling` | 落地后位置与血量一致 | 普通跳跃误报坠落 |
| 8 | 溺水 | 水下、氧气下降 | 反射上浮 | 氧气恢复、头部出水 | 只报告不上浮 |
| 9 | 自动垫桥 | 5 格壕沟、有整方块 | `goto` 触发垫桥 | 对岸连续方块，身体到达 | 无材料仍规划桥或走到一半停住 |
| 10 | 楼梯脱困 | 1–2 格深坑 | 挖台阶或垫脚离开 | 身体回到地面，不再 `NoPath` | 原地跳或反复重算 |
| 11 | 箱子存取 | 附近有箱子、背包有杂物 | `deposit`，必要时取回 | 箱子与背包数量互补 | 界面打开但物品未移动却报成功 |
| 12 | 熔炼铁器 | 有熔炉、粗铁、燃料 | `smelt` | 产物入包、燃料减少 | 把“开始烧”当成“已产出” |
| 13 | 铁套连续计划 | 铁锭、燃料、可达工作台 | `run_plan` 熔炼并制作（legacy 编译或手工下发） | 多件铁装按步骤出现，guard/证据/检查点齐全 | 步骤间空闲重排、重复熔炼或越出目标族 |
| 14 | 床与重生点 | 有床、夜间 | `sleep` | 时间到白天，重生点更新 | 白天或雷雨时白跑 |
| 15 | 空场节拍 | 无评论 45 秒、身体在线 | 环境台词，不带技能 | `decision_log` 出现 `idle:*`，有字幕 | 完全静默或短时重复 |
| 16 | 危险反应 | 触发 `reflex` | 主动短台词，不带技能 | `decision_log` 出现 `reflex:*` | 只写 `world_event`，直播无反应 |
| 17 | 分段续跑 | 长距离 `goto` / 大批量挖掘 | 到预算返回 `remaining` + `nextHint` | 下一轮继续剩余进度 | 超时后从头重做 |

## 证据写法

```text
场景：<编号 + 名称>
身体：<位置 / 血量 / 饥饿 / 手持>
决策：<decision id + skill + outcome.status>
证据：<changes / 方块查询 / 背包差量>
未确认：<unconfirmed，没有就写“无”>
失败条件：<problem / remaining / attempts>
```

当前通过范围和未验收项以[验证清单](verification.md)为准。单个场景通过不代表
完整生存链已经生产可用。
