# 文档索引

换对话、换人接手，从这里开始读。

| 文档 | 用途 |
| --- | --- |
| [technical-design.md](technical-design.md) | **技术记忆基线**。架构、决策、协议、路线图都在这。 |

| [adr/](adr/README.md) | 架构决策记录。每条都写明背景、决策、后果。 |

## 阅读顺序

1. 先读 [technical-design.md](technical-design.md) 的「一页纸速查」。
2. 需要细节时按章节跳读。
3. 想知道「为什么这么选」，读对应 ADR。
4. 讨论时用 [GLOSSARY.md](../GLOSSARY.md) 里的词。

## 维护规则

- 新的拍板结论先进 ADR，再更新技术设计。
- 技术设计里不写「待讨论」的猜测，未定的进第 19 节。
- 已废止的方案不删除，标状态并链接到取代它的 ADR。
