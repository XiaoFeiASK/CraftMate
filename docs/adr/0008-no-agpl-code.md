# ADR-0008：不复制 AGPL 项目代码

- 状态：已采纳
- 日期：2026-11-02

## 背景

AstrBot 是 AGPL-3.0，工程结构和安全流水线有参考价值。项目可能需要闭源或商业化。

## 决策

AstrBot 只作为设计参考。不复制代码、不 fork、不做进程内链接。

## 可借鉴

- 流水线阶段顺序：便宜闸门在前，模型在中，TTS 与字幕在后。
- StrategySelector 的可插拔策略结构。
- 输入与输出共用同一个审查入口。
- TTS Provider 清单。

## 后果

- 所有借鉴点必须独立重写。
- 如未来确需复用某模块，只能走独立进程 + HTTP 边界，并需律师判断是否构成衍生作品。
- 代码评审时把「来源是否是 AGPL 项目」作为检查项。
