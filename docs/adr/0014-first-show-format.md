# ADR-0014：首播采用单一主线目标

- 状态：已采纳
- 日期：2026-11-02

## 背景

首播需要决定节目形态：自由生存、单一主线目标，还是分段节目单。

## 决策

首场设一个明确目标（例如盖一间带床和箱子的小屋），允许约 20% 的时间被弹幕打断去处理观众请求。

## 理由

- 自由生存前 30 分钟大概率在砍树找羊，新观众会流失。
- 单一目标让画面始终有进度感，也让 Agent 的承诺有落点。
- 保留 20% 打断空间，观众才不会觉得自己的评论没用。

## 后果

- 导演层需要一个「主线进度」概念，而不只是当前任务队列。
- 打断过多时，导演层要主动把话题拉回主线。
- 分段节目单留到 M4 再评估。
