# ADR-0007：抖音接入做官方与抓取双实现

- 状态：已采纳
- 日期：2026-11-02

## 背景

抖音是首发平台，用专用开播号。官方开放平台的直播互动能力需要资质与审核；第三方抓取链路不稳定但开发期可用。

## 决策

定义 `CommentSource` 接口，提供 `douyin-official` 与 `douyin-capture` 两个实现。上层只依赖 `AudienceEvent`。

## 理由

- 官方链路的审核周期不受开发控制，不能阻塞开发。
- 抓取链路可以早早在真实弹幕流上联调。
- 平台差异必须隔离在接入端，不能渗透到仲裁与技能层。

## 后果

- 抓取实现需要自行处理签名刷新、重连、风控。
- 正式上线优先切官方实现。
- 更换平台时只新增适配器，不改业务代码。
