# ADR-0003：客户端 Mod 驱动真实玩家账号

- 状态：已采纳
- 日期：2026-11-02

## 背景

游戏执行有三种形态：服务端假玩家、客户端 Mod 驱动真实账号、双端 Mod。用户已有专用游戏账号，并要求 Agent 直接操作该账号。

## 决策

使用 Fabric 客户端 Mod，直接驱动真实玩家账号的输入层。不造 NPC，不做服务端权威。

## 理由

- 账号本身就是 Agent 的身体，画面即直播画面。
- 相机、动画、HUD 都在客户端，表现力最好。
- 不需要操作系统级键鼠模拟，不抢焦点、不需要辅助功能权限。
- 单人世界的集成服务器让 Mod 能拿到权威状态。

## 后果

- 一个账号只有一个身体，人和 Agent 不能同时操作，必须有控制权三态。
- 操作员接管时，Agent 必须立即停止所有动作。
- WS 断开必须释放所有按键，否则会出现卡键。
- 自动化只允许在自有存档或授权服务器中使用。
