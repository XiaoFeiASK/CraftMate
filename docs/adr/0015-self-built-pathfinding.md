# ADR-0015：寻路自研，Baritone 仅作对照

- 状态：已采纳
- 日期：2026-11-02

## 背景

Baritone v1.17.0 支持 1.21.11 + Fabric，能力成熟，但采用 LGPL-3.0。项目许可证是 MIT OR Apache-2.0，且可能商业化。

## 决策

正式版使用自研 A*。开发期可单独安装 Baritone 做可达性与耗时对照，但不得进入发行包。

## 理由

- 自研没有许可传染风险，也不必为闭源分发做额外合规。
- 本项目只需要「走到某处、挖某类方块、返回」，不需要 Baritone 的全功能。
- 自研可以把每 tick 预算、取消、进度汇报直接做进 Mod，而不是包一层。

## 后果

- 寻路开发量增加，预计 1–2 周。
- 复杂地形、跨维度、长距离导航的质量需要单独测试。
- 如果后续确认接受 LGPL 并完成合规流程，可以重新评估，但不作为默认路径。
