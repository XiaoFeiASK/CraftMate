# ADR-0004：本地单人世界作为直播场地

- 状态：已采纳
- 日期：2026-11-02

## 背景

候选是自建 Fabric 服务器与本地单人世界。用户确认使用本地单人世界，并新建直播存档。

## 决策

直播运行在本地单人世界。不部署服务端 Mod，不做多人规则，不做反作弊。

## 理由

- 单人世界没有跨进程通信，Mod 可以直接拿到权威状态。
- 部署链路最短，Mac 上不需要额外服务端。
- 新建存档可以按节目需要选择地形和初始资源。

## 后果

- 必须关闭「失焦暂停」（`pauseOnLostFocus:false`），否则切窗口会冻结游戏。
- 世界状态和存档在直播机上，需要本机备份策略。
- 未来如果要多人或无人值守，需要重新评估，不在当前范围。
