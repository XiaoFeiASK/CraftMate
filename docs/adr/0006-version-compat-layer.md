# ADR-0006：版本不锁死，用 compat 层隔离差异

- 状态：已采纳
- 日期：2026-11-02

## 背景

用户表示《我的世界》版本不需要锁死，1.2x 都可以切换。但 Mod 的 Mixin 与映射对版本高度敏感。

## 决策

当前基线为 1.21.11。Mod 内部分为 `core` / `api` / `compat` 三层，版本相关代码只放 `compat`。

## 约束

1. `core` 不出现任何 Minecraft 类型。
2. 协议只出现语义 ID、整数坐标、tick。
3. `fabric.mod.json` 只声明实测过的版本范围。

## 后果

- 换版本时新增 `compat/vX_X_X`，内核与协议不变。
- 不在未测试的版本上宣称支持。
- 同一时间只维护一个兼容目标，避免多版本矩阵的测试成本。
