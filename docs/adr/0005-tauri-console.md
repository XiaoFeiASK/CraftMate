# ADR-0005：管理端用 Tauri，交互按原生桌面程序做

- 状态：已采纳
- 日期：2026-11-02

## 背景

用户明确不要「Web 那种 UI」，要类似本地程序的形态。团队规模是单人为主，需要管理端与内核共享类型。

## 决策

使用 Tauri 2 + React + TypeScript。技术上是 Web 渲染，交互形态必须按原生桌面程序设计。

## 约束

- 系统标题栏、菜单栏、托盘、Dock 图标。
- 无浏览器地址栏、无标签页、无卡片瀑布流。
- 固定多面板、可拖拽分栏、`Cmd+K` 命令面板。
- 关闭窗口隐藏而不是退出。
- 多显示器位置记忆。

## 后果

- 如果「不要 Web」被解释为禁止 Web 渲染，需要改 Avalonia 或 Qt，代价是跨语言和更慢的迭代。
- 推流画面不能使用管理端窗口，必须由 OBS 直接采集游戏。
