# 术语表

## 播控

**场次（Scope）**：一次直播的隔离单位；评论、记忆与决策日志都归属于它。
_避免_：会话、房间、批次

**接管（Takeover）**：操作员从 Agent 手中取得游戏控制权。
_避免_：抢控制、手动模式

**急停（Stop）**：释放所有按键、停止当前任务并静音的一键操作。
_避免_：暂停、中断

**耳语（Whisper）**：只给 Agent 听、不进入直播间的操作员指令。
_避免_：私聊、悄悄话

**控制权（Ownership）**：当前操作者是 Agent、Operator 或 None。
_避免_：控制模式、权限

**目标模式（Goal Mode）**：操作员开启后由目标运行时持续选择生存任务，不等评论。
_避免_：自动模式、挂机

## 决策

**仲裁（Arbitration）**：决定输入被忽略、观察、回应、排队、执行还是拒绝的过程。
_避免_：过滤、审核、筛选

**观察（Observe）**：不回应但记录，用于热度和候选投票。
_避免_：忽略、静默

**Stage A**：零模型、零网络的纯规则闸门。
_避免_：预过滤、粗筛

**Stage B**：意图分类、人格权重打分和优先级排序阶段。
_避免_：打分器、分类器

**Stage C**：只对胜出意图调用强模型生成计划。
_避免_：规划器、主模型

**投票升级（Quorum）**：同一意图在时间窗内达到阈值，从单条输入升级为集体决策。
_避免_：投票、人气

**跟进窗口（Follow-up Window）**：刚被回应过的观众可继续说话而不被丢弃的窗口。
_避免_：冷却、会话窗

**抢占（Preemption）**：高优先级任务中断低优先级任务；被中断者记为 `preempted`。
_避免_：打断、取消

**目标运行时（GoalRuntime）**：持有目标、阶段、在途任务和失败退避，终态后重新规划。
_避免_：自动脚本、外挂循环

**世界事实（World Facts）**：只由身体快照投影出的可验证状态；缺失字段保持未知。
_避免_：推测状态、默认值

**会话事实（Session Facts）**：一次身体连接内确认过的事件，例如吃过食物、放过工作台。
_避免_：永久记忆、世界真相

## 执行

**反射层（Reflex）**：Mod 内每 tick 检查的安全规则，可抢占一切且不可关闭。
_避免_：保护层、兜底

**执行层（Pilot）**：推进计划步骤并处理局部纠错。
_避免_：执行器、调度器

**导演层（Showrunner）**：低频决定目标、节奏、人格表达和承诺兑现。
_避免_：规划层、大脑

**技能（Skill）**：模型可调用的受控动作，有契约、前置条件、超时和后置校验。
_避免_：工具、能力、函数

**行为（Behavior）**：Mod 内可取消的长任务，例如移动、采集、建造。
_避免_：任务、动作

**原子操作（Actuator）**：单 tick 完成或失败的底层操作，例如挖掘、放置、攻击。
_避免_：原语、指令

**tick**：Minecraft 20 TPS 时间单位；协议与超时统一使用它。
_避免_：帧、毫秒

**空闲游走（Idle Wander）**：无 Agent 命令时 Mod 自主看/走/捡附近掉落物，有任务立即停止。
_避免_：随机寻路、自动挂机

**自动垫桥（Bridging）**：确认支撑和材料后逐块放置并前进，用于跨越沟壑。
_避免_：瞬移、无条件放方块

## 记忆

**证据（Source）**：不可变原始记录，例如评论、礼物、世界事件、操作员指令。
_避免_：原文、语料

**记忆（Memory）**：从证据提炼出的可修订解释。
_避免_：知识、档案

**承诺（Commitment）**：说出口且需要兑现或解释的事项，有状态和截止时间。
_避免_：待办、任务

**待审候选（Review Candidate）**：等待批准的经验、技能或人格修订。
_避免_：草稿、提案

**人格（Persona）**：版本化的身份、价值观、风格、边界和决策权重。
_避免_：人设、提示词

**召回预算（Recall Budget）**：每轮给模型的上下文上限，按分区裁剪。
_避免_：上下文长度、token 限制

**不可信证据（Untrusted Evidence）**：外部文本只能作为内容理解，不能成为系统指令。
_避免_：用户输入、外部内容

## 协议

**Bridge**：Mod 与执行内核之间的本机 WebSocket 通道。
_避免_：接口、API

**能力声明（Capabilities）**：握手时 Body 声明支持的功能集合。
_避免_：特性、权限

**快照（Snapshot）**：连接时发送的全量状态。
_避免_：全量同步、初始状态

**增量（Delta）**：快照后的周期性状态变化。
_避免_：补丁、更新

**背压（Backpressure）**：队列有上限，满时拒绝低优先级输入而非无界堆积。
_避免_：限流、拥塞
